<h4>Mathematical Theory</h4>

The 1D Time-Independent Schrödinger equation can be rewritten in the standard second-order form without first derivatives:

$$
\frac{d^2\psi}{dx^2} + k^2(x)\psi(x) = 0, \quad \text{where } k^2(x) = \frac{2m}{\hbar^2}[E - V(x)]
$$

Numerov's algorithm achieves a local truncation error of $\mathcal{O}(h^6)$ by taking advantage of the absence of $\psi'(x)$:

$$
\psi_{n+1} = \frac{2\left(1 - \frac{5h^2}{12}k_n^2\right)\psi_n - \left(1 + \frac{h^2}{12}k_{n-1}^2\right)\psi_{n-1}}{1 + \frac{h^2}{12}k_{n+1}^2}
$$

def numerov_step(psi_curr, psi_prev, k_sq_next, k_sq_curr, k_sq_prev, h):
    """Calculates psi_{n+1} using Numerov's three-point formula"""
    c = h**2 / 12.0
    numerator = 2.0 * (1.0 - 5.0 * c * k_sq_curr) * psi_curr - (1.0 + c * k_sq_prev) * psi_prev
    denominator = 1.0 + c * k_sq_next
    return numerator / denominator

def shoot_schrodinger(E, V_func, x_grid, h, m=1.0, hbar=1.0):
    """Integrates outward from x=0 to find boundary mismatch"""
    N = len(x_grid)
    psi = np.zeros(N)
    psi[0] = 0.0          # Boundary condition at x=0 (odd parity or wall)
    psi[1] = 1e-4         # Small seed value
    
    k_sq = (2.0 * m / hbar**2) * (E - V_func(x_grid))
    
    for i in range(1, N - 1):
        psi[i+1] = numerov_step(psi[i], psi[i-1], k_sq[i+1], k_sq[i], k_sq[i-1], h)
        
    return psi[-1] # Return value at outer boundary x_max

<h4>Symplectic Geometric Properties</h4>

Standard Runge-Kutta methods suffer from artificial secular energy dissipation over long integration intervals. A **symplectic integrator** preserves the phase-space volume (Poincaré invariants) and maintains the total Hamiltonian on an exact shadow trajectory:

$$
\mathbf{r}(t + \Delta t) = \mathbf{r}(t) + \mathbf{v}(t)\Delta t + \frac{1}{2}\mathbf{a}(t)\Delta t^2
$$

$$
\mathbf{v}(t + \Delta t) = \mathbf{v}(t) + \frac{1}{2}[\mathbf{a}(t) + \mathbf{a}(t + \Delta t)]\Delta t
$$

    # Half-step velocity update
    a_curr = force_func(r)
    v_half = v + 0.5 * a_curr * dt
    # Full-step position update
    r_next = r + v_half * dt
    # Complete velocity update with new acceleration
    a_next = force_func(r_next)
    v_next = v_half + 0.5 * a_next * dt
    return r_next, v_next
